# JSON Strictness By Accident Example

This Python script demonstrates the concept of 'Strict by Accident' JSON. It shows how a JSON string that is technically invalid according to strict standards might still be parsed by some lenient parsers, while a strict parser like Python's `json` module will correctly reject it, highlighting the importance of understanding parser strictness.

## Language

`python`

## How to Run

Save the code as `strict_json_demo.py` and run it from your terminal using: `python strict_json_demo.py`
